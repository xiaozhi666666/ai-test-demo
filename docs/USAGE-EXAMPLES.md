## 💡 常用命令速查

### 开始解题
```bash
/solve-problem <编号>          # 题目编号
/solve-problem <URL>            # LeetCode URL
```

### 流程控制
```
"继续"                          # 继续下一步
"暂停"                          # 暂停流程
"取消"                          # 取消流程
"重试"                          # 重试上一步
"跳过"                          # 跳过当前步骤
```

### 查看状态
```
"当前状态"                      # 查看进度
"显示历史"                      # 查看操作历史
"查看 PR"                       # 查看相关 PR
```

### 修复控制
```
"接受当前实现"                  # 接受非最优代码
"手动修改"                      # 切换到手动模式
"增加修复次数"                  # 请求更多修复机会
```
